# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React with Vite. The application must remain deployable as a static site with no backend.

## Users

The primary users are teachers who need to prepare visual material quickly without learning a professional editor. The product must also remain useful and understandable for students, families, office workers, and the general public.

## Product Purpose

Image in Place makes common image operations fast and approachable. Success means a first-time visitor can drop in an image, choose a task in plain language, see the result immediately, and export it without creating an account.

## Positioning

An education-friendly image toolbox in which every operation happens locally in the browser. It combines focused, one-purpose workflows with a shared workspace, so users do not need to upload sensitive classroom images or learn a complex professional editor.

## Operating Context

Typical tasks include preparing images for presentations and worksheets, resizing or compressing classroom material, annotating visual explanations, anonymizing people or information, converting formats, and producing assets for learning platforms or everyday sharing.

## Capabilities and Constraints

- All image processing must run in the browser; there is no backend.
- No account is required.
- The interface is available in Spanish (source language), Galician, Catalan, Basque and English.
- The interface must be simple, modern, responsive, and usable with keyboard and touch.
- Imported images are presented in a selectable gallery before editing.
- Users can apply one set of operations to multiple selected images and download the results as a ZIP archive.
- Batch operations must work without reviewing images individually: select images, choose an action, configure it in the right sidebar, and apply to the selection. The sidebar displays selected-image metadata when no action is active. Visual cropping and privacy masking are individual editing tasks.
- Primary application surfaces fit the viewport; long content scrolls within its own work area instead of the document.
- `imageinplace.com` is the preferred domain if it is available to register.
- The first release should establish an extensible foundation for additional image tools.

## Brand Commitments

The provisional product name is **Image in Place**, derived from the preferred domain. The voice should be direct, calm, and practical rather than technical.

## Evidence on Hand

No testimonials, usage figures, customer logos, or proprietary visual assets are available. Future work must not fabricate commercial claims.

## Product Principles

- Start with the user's task, not image-editing terminology.
- Keep source images private by processing them locally.
- Make the useful default obvious while allowing precise control.
- Support education-specific workflows without turning the product into a school-only tool.
- Show the result before asking the user to download it.

## Accessibility & Inclusion

Core workflows must be keyboard accessible, provide visible focus states, respect reduced-motion preferences, meet readable contrast targets, and use touch targets of at least 44 by 44 pixels.
