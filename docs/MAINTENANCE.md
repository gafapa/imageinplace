## Disposable output

`dist/` is regenerated by `npm run build`. `artifacts/browser/` contains generated screenshots and synthetic project/PDF output. Coverage, Vite caches, logs, and obsolete assistant histories are disposable. Generated output must stay ignored. Only remove explicitly identified paths inside this repository; do not follow external links or use broad deletion commands.
